# PR119 transition softness comparison

Additive offline evidence, pending owner visual acceptance. The quieter Earth
and Green sources, A/B/C interiors and existing 0.20-0.80 prototype are unchanged.
No treatment is selected or integrated by this comparison.

- [Meandering-boundary comparison](meandering_boundary_varied_comparison.png)
- [Mixed-terrain comparison](mixed_24x16_comparison.png)
- [Input identities, exact coordinates, layout hashes and validation](manifest.json)

Read columns **left to right**: Current **0.20-0.80**, Candidate A **0.15-0.85**,
Candidate B **0.10-0.90**. Each board uses the identical saved layout and variants
in all three columns. Top: full layout at 64 pixels per tile, approximating the
production half-scale display without camera zoom or runtime shading. Bottom:
the same 8x6-cell detail window in all columns, at 128 pixels per tile. Crop
origins are cell (2,1) for meandering and (12,4) for mixed terrain.

Only the remapping of existing signature-mask weights varies:

```text
weight = smoothstep((old_weight - lower) / (upper - lower))
```

The original mask math, 0.5 contour, nine anchors and coordinate inventory are
unchanged. Both candidate ranges are symmetric about 0.5. Materials are read
directly from the saved refined PNGs; this tool never refines sources or changes
texture parameters. Saved B/C interior pixels are reused verbatim. Current is
required to reproduce every saved baseline/interior tile pixel exactly.

All three treatments are validated across the existing **41-signature subset
plus four B/C records**, including signatures not present in these two layouts:

| Treatment | Partially blended texels | Compatible edge pairs | Layout adjacencies | Raster/mask anchors |
| --- | ---: | ---: | ---: | ---: |
| Current 0.20-0.80 | 64,986 | 836 | 900 | 369 |
| Candidate A 0.15-0.85 | 77,934 | 836 | 900 | 369 |
| Candidate B 0.10-0.90 | 92,601 | 836 | 900 | 369 |

Each edge comparison has **zero** channel difference. Counts are across the
subset, not a full refined 94-signature atlas. Widths are old-mask weight ranges,
not fixed pixel distances. A is moderately broader; B is broader still. Wider
feathering softens boundaries but can make narrow features look less distinct
even with unchanged pure-material centers and contour geometry. Existing rounded
stepping remains; no geometry smoothing, edge repair or shading change occurs.

Reproduction uses the new [offline comparison tool](../../../../tools/ground-transition-softness.py):

```powershell
python -B tools/ground-transition-softness.py --check
python -B -m unittest discover -s tests -p 'static_ground_softness_test.py' -v
```

`--check` regenerates and compares all generated bytes in memory. `--write`
creates only a new fixed comparison directory and refuses an existing one.
No dependency installation, project execution or temporary output is needed.
The inherited source tools are imported read-only; their writers are never
called. `.gdignore` excludes this evidence from Godot import, and the local LF
rule keeps the generated manifest reproducible after checkout.

No Godot, graphical, performance or runtime verification is performed. Production
resources, TileSet, peering, procedural generation, shading, PR100 evidence and
the original PR119 prototype remain unchanged. See the
[prototype documentation](../../../../docs/GROUND_ART_REFINEMENT_PROTOTYPE.md)
for the original study and its separate validation record.
