# IBM Plex Sans

Unmodified Regular, Medium and SemiBold TrueType fonts from the official
[IBM Plex repository](https://github.com/IBM/plex), revision
`71f558992315a12ca1f06a2215d57962a1992162`.

Source directory:
[`packages/plex-sans/fonts/complete/ttf`](https://github.com/IBM/plex/tree/71f558992315a12ca1f06a2215d57962a1992162/packages/plex-sans/fonts/complete/ttf).
The upstream [license](LICENSE.txt) is preserved verbatim: SIL Open Font License
1.1, with IBM's copyright and reserved font-name notices. These fonts are bundled
assets, not a dependency on an installed system font.

`assets/ui/b1_theme.tres` uses Regular for body text, Medium for buttons/progress,
and SemiBold for titles. Only these three `.ttf` files are added to the restricted
runner's input allowlist, together with their three matching `.ttf.import`
metadata sidecars. The sidecars were generated by the pinned engine in the
first B1 external stage and copied into source without caches. They are required
because the runner rejects unexpected files outside `.godot/` after import.

These three sidecars must retain LF line endings in the working checkout as well
as Git. The root `.gitattributes` pins `text eol=lf` for their exact paths, overriding
`core.autocrlf=true`. PR #78's failed stage showed Godot rewrote only CRLF to LF
(36 line endings per file); the resulting bytes exactly matched the committed
blobs, including all UIDs, paths and import parameters. Normalizing the checkout
therefore changes no metadata or semantics and preserves the runner's byte checks.
The previous failed stage/evidence remain preserved. A fresh Native attempt still
requires explicit owner authorization; normalization alone is not runtime PASS.
