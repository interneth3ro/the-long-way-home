## Safety invariants: evidence and limits

### UID and dependency safety

The checker still follows literal resource paths/global classes, verifies file
existence, rejects development paths, checks unique global classes/UIDs, and rejects
unresolved dependency UIDs. Header declarations now contribute identities rather
than being falsely treated as missing sidecar dependencies. Duplicate/malformed
header declarations fail; external UID/path agreement is additionally checked.

fixtures still run. Previously three were masked by the B1 Theme self-UID error;

the intended injected dependencies. The six new methods below add direct evidence.
The source-format distinction was inspected against Godot's text loader; no engine
compatibility or gameplay correctness is inferred from these static tests.
